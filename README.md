# Daily Progress — দৈনিক অগ্রগতি

একটা সুন্দর dark-themed personal daily progress tracker।

## Features

- **Dashboard** — আজকের overview, stats, streak, quick add
- **Tasks** — Daily to-do list (complete / incomplete)
- **Goals** — Long-term goal + daily progress log
- **Study Tracker** — Subject-wise study time tracking
- **Journal** — Daily journal + mood tracker
- **Streak** — Consecutive active days
- **Export / Import** — Data JSON হিসেবে backup নেওয়া যায়

## How to use

1. `index.html` file টা browser এ open করো (Chrome / Firefox / Edge)
2. অথবা কোনো static hosting এ upload করো (Netlify Drop, GitHub Pages, Vercel)

সব data তোমার browser এর **localStorage** এ save হয়।  
অন্য device এ নিতে চাইলে Export করে JSON download করে নতুন device এ Import করো।
